# 简词键盘 / QJMobile

基于青简 v0.1.4 的独立 iPhone 个人移植版。26 键拼音输入，候选词下附一条英文译词；离线运行，无需“允许完全访问”。

第一版面向 iOS 18 及以上的 iPhone，包含中英文、数字标点、候选横向滚动、长按删除、取消输入、横竖屏和深浅色模式。首版没有九宫格、双拼、云联想、大型语言模型、语音、输入日志或用户词频学习。

## 获取安装包

打开本仓库 Actions → **Build iPhone keyboard** → **Run workflow**，选择 `full`。
构建成功后，下载页面底部的 `QJMobile-full-…` 文件，解压取得 `QJMobile.ipa`。
此包未签名，需通过 AltStore Classic 签名安装，不能直接点 IPA 安装。

首次排查安装问题可选择 `bootstrap`：此包只验证基础键盘外壳，不提供中文候选。安装 bootstrap 与 full 时请使用同一 Apple 账号；full 会更新同一个应用。

## Windows 安装

详见 [中文安装指南](docs/安装与续签.md)。用 AltServer 安装 AltStore Classic，再在 AltStore 中导入 IPA，**保留简词键盘扩展**。免费账号需在 7 天内续签。

## 在手机上使用

设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → 简词键盘。
输入框中按住地球键切换到简词。无需开启“允许完全访问”。

- 输入 `kaifa`，点“开发”，英文译词仅作辅助，不会一起上屏。
- 空格选首个候选；选短词后剩余拼音继续显示。
- 有拼音时回车完成当前组句；再次回车插入换行或交给应用处理搜索、发送。
- “取消”只清空未上屏拼音；候选栏末尾的原始拼音可原样输入。
- “译词”开关只保存在键盘自身；“中 / EN”切换英文直接输入。
- 英文或大写字母直接输入；中文模式下使用 `v` 输入拼音中的 ü。

密码框及拒绝第三方键盘的应用会使用系统键盘。扩展停用或输入位置变化时清除未上屏拼音。
