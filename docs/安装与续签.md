# Windows 安装与续签

## 准备

需要 Windows 电脑、运行 iOS 18 或以上的 iPhone、连接线、Apple 账号，以及未签名 `QJMobile.ipa`。
账号登录在 AltServer / AltStore 内完成，不要把密码上传到仓库或填到源码里。

按照 AltStore 官方说明安装其要求的 iTunes、iCloud 和 AltServer。系统已安装的 Apple 软件可能需要按官方说明调整版本：
https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows

## 首次安装

1. 用连接线连接 iPhone 与电脑，在手机上允许“信任此电脑”。
2. 启动 Windows 的 AltServer，在任务栏菜单中选择 Install AltStore → 你的 iPhone。
3. 在 AltServer 登录 Apple 账号，按提示完成 AltStore Classic 安装。
4. 在 iPhone 的设置 → 通用 → VPN 与设备管理中，信任该开发者；按提示在隐私与安全性中开启开发者模式，可能需要重启手机。
5. 将 `QJMobile.ipa` 放到 iPhone 的“文件”中。在 AltStore 的 My Apps 页面点 +，选中 IPA。
6. **如果询问是否删除扩展，选择保留简词键盘扩展。** 这个项目的主应用与键盘扩展分别需要一个 App ID。删除扩展后将只能打开引导应用，无法启用键盘。
7. 打开简词键盘主应用，按其教程在设置中添加键盘。
8. 在备忘录中按住地球键，选择简词，输入 `kaifa` 和 `nihao`。

不需要越狱或付费开发者账号。免费账号受 Apple 的侧载应用数与 App ID 数限制；AltStore 自身也占一个应用位置。额度不足时，按 AltStore 的提示等待过期或调整已安装的侧载应用。

## 每周续签

免费签名通常 7 天后到期。到期前保证 AltServer 正在电脑上运行，并且能连接手机。在 AltStore → My Apps 点 Refresh All。
可用同一 Wi-Fi 与 iTunes Wi-Fi 同步刷新；不稳定时使用连接线。

续签是重新签名已有安装包，**通常不需要每周重新云端编译**。源码或功能更新后才下载新 IPA。
不要删除应用来续签；删除应用会清除键盘自身保存的设置。

如果已到期导致应用无法打开，先按 AltStore 官方恢复步骤让 AltStore 本身重新可用，再刷新简词。不同系统版本的提示可能略有差异。

## 排查

- 设置里找不到简词键盘：检查安装时是否保留了键盘扩展。
- 提示开发者不受信任或无法验证：核实签名、开发者模式、网络连接以及账号登录。
- 输入法无法在某个应用中出现：先在备忘录测试；密码框和部分应用会禁止第三方键盘。
- 中文无法输入、显示“基础键盘验证包”：安装的是 bootstrap，需换成 full。
- 中文引擎报错：切换系统键盘，再重新选择简词；保留故障截图并记录系统版本和操作步骤。
